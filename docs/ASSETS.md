## Typefaces

Self-hosted from `src/fonts/` and loaded with `next/font/local`. No request is made to a font
service. The licence text for each sits in `src/fonts/licenses/`, which is what the SIL Open Font
License asks for when fonts are redistributed, including in a public repository.

| Typeface   | Role                          | Owner  | Source                                                                                                       | File in `src/fonts/`       | Changes made                                   |
| ---------- | ----------------------------- | ------ | ------------------------------------------------------------------------------------------------------------ | -------------------------- | ---------------------------------------------- |
| Geist      | All text                      | Vercel | [github.com/vercel/geist-font](https://github.com/vercel/geist-font), via `@fontsource-variable/geist` 5.3.0 | `Geist-Variable.woff2`     | Latin subset as published, otherwise unchanged |
| Geist Mono | Code, readouts, the code dock | Vercel | Same, via `@fontsource-variable/geist-mono` 5.3.0                                                            | `GeistMono-Variable.woff2` | Latin subset as published, otherwise unchanged |

The site this one's structure follows is set in General Sans (Fontshare). It was not used here:
its licence (ITF Free Font License 2.0) allows self-hosting but not redistribution, which
committing the font files to a public repository would be, and it does not allow subsetting.

## Portrait

`public/portrait/` is generated by `npm run assets:portrait` from the photograph Ajay supplied
(kept outside the repository, in `.context/source/`). The person is separated from the background
with macOS Vision's foreground-subject mask, cropped to the figure and written as:

| File             | Size     | Used for                                                                                                   |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `cutout.webp`    | 799×1200 | The source the hero's dots are sampled from; the photo behind them; the menu; the story's portrait chapter |
| `cutout-bw.webp` | 799×1200 | The black-and-white portrait in the menu                                                                   |
| `avatar.webp`    | 512×512  | The dotted avatars in the contact card and the footer                                                      |

## Storefront captures

`public/work/<slug>.webp` are screenshots of six live storefronts, taken on 18 November 2026 for
the earlier portfolio and cropped to 960×600 by `npm run assets:work`. Each is shown as a dot
matrix behind the brand's name and linked to the storefront it shows.

These are not licensed assets. Each storefront, its design, its photography and its trademarks
belong to the brand. The captures are used only to identify work Ajay contributed to, at reduced
size, with a link to the source and this note on the page:

> Brands and storefronts I have contributed to professionally, as part of agency and product
> teams. Names and storefronts belong to their owners; listing them here does not imply
> endorsement.

Before publishing, please check two things only you can know:

1. That no agency or employment agreement (EcomExperts, Marmeto, Kinect AI) restricts naming a
   brand or showing its storefront in a personal portfolio.
2. That you are comfortable with each capture. They show the stores as they looked on capture
   day, which was during Black Friday promotions.

To remove a brand, delete its entry from `work.projects` in `src/content/sections.ts` and its
file in `public/work/`.

## Land outline

`src/components/site/sections/land-mask.ts` says which cells of a 3-degree grid are land. It was
generated once from [Natural Earth](https://www.naturalearthdata.com/)'s 1:110m land polygons
(public domain, via the `world-atlas` package) with `d3-geo`. Neither package is a dependency of
the site.

## Design reference

The structure, layout and interactions of this site follow
[inacionakiti.com](https://inacionakiti.com), the portfolio of Inacio Nakiti, at Ajay's request.
That site's code, copy, images and font files are not used: everything here was written for this
site, with different content, colours, typeface and particle shapes. If you publish this site,
consider crediting the reference, and note that a site this close to an awarded original will be
recognised by people who know it.
